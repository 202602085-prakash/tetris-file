# Tetris Game

A simple browser-based Tetris game made with HTML, CSS, and JavaScript.

## Features
- Classic 10×20 Tetris board
- 7 standard Tetris pieces
- Move, rotate, soft drop, and hard drop
- Score, lines, and level system
- Next-piece preview
- Pause with **P**
- Responsive layout

## Run locally
Open `index.html` in a web browser.

## GitHub Pages
After uploading, enable GitHub Pages from the repository's **Settings → Pages** and select the `main` branch.
